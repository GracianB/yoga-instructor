## Detalles técnicos

| Feature | Detalle |
|:--|:--|
| **i18n** | ES / EN, persistencia en `localStorage`, override por `?lang=en` |
| **Tema** | Claro / oscuro, auto-detecta `prefers-color-scheme`, override por `?theme=dark` |
| **Timeline nativa** | Componente horizontal HTML/CSS propio (sin dependencias externas) |
| **Reading progress** | Barra fija superior, gradiente verde → dorado |
| **Scroll-spy** | Navegación activa según sección visible |
| **Counters animados** | Stats numéricas al entrar en viewport |
| **Tags flotantes** | Contenidas al hero, ocultas en pantallas < 1180px |
| **Reveal on scroll** | IntersectionObserver, fade + translateY |
| **Tipografía** | Fraunces (variable, opsz 9–144) + Inter/Manrope |
| **Responsive** | Mobile-first, breakpoints en 980px / 560px |
| **Accesibilidad** | Skip link, focus-visible, ARIA, `prefers-reduced-motion` |
