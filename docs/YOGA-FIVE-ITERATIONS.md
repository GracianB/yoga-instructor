# Cinco iteraciones de Yoga

1. Inspección de silueta completa con el dibujo anatómico existente.
2. Render canvas protegido frente a cargas antiguas y recuperación del dibujo original si falla la imagen.
3. Personalización del estudio desplegable y controles de inspección agrupados.
4. Entrada directa a la práctica desde la portada, navegación con estado y ES/EN.
5. Referencias versionadas, contratos de compilación y pruebas de las posturas actualizados.

Estas son cinco iteraciones de una misma versión en la PR 190. No equivalen a cinco aplicaciones publicadas. El canvas dibuja el vector anatómico existente; no es todavía un rig Rive con huesos nativos. La suite de navegador completa sigue siendo necesaria antes de publicar.
